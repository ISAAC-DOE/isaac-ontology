# ISAAC ontology

The ISAAC AI-ready record schema and controlled vocabulary, maintained in this
repository's [wiki](https://github.com/ISAAC-DOE/isaac-ontology/wiki).

Start with [Home](https://github.com/ISAAC-DOE/isaac-ontology/wiki) or
[Write Your First Record](https://github.com/ISAAC-DOE/isaac-ontology/wiki/Write-Your-First-Record).

The wiki's generated sections are produced from `data/vocabulary.json` and the
validator in the ISAAC portal. Vocabulary changes go through a proposal in the
portal; the portal pushes the approved change here.
